Why bother using Vim in the age of AI

Written by Naphat Amundsen

In this day and age during the AI uprising, one may wonder, why care about having a good code editor setup?

I say, if you still care about having good products, you must at least read and understand the central parts. Now that we can generate so much code, effective navigation of code and tools is essential.

Vim to me, is not just an editor, but a convention. The keybindings of Vim is probably the most ubiquitous set of keybindings there are related to programming. You can kinda find Vim keybindings seemingly everywhere. Like, most code editors have Vim-mode, and a lot developer tooling has Vim-like keybindings, you can get Vim-mode in the command line. And this to me, is the "superpower" knowing Vim gives you.
